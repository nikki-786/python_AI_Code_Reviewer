# Python AI Code Reviewer 🚀

## Overview

Python AI Code Reviewer is an AI-powered tool designed to analyze source code and provide intelligent feedback to developers.

The main objective of this project is to help developers improve their code quality by identifying possible issues, suggesting improvements, and providing useful code review insights using Artificial Intelligence.

---

## Features

- 🔍 Analyze source code
- 💡 Provide code improvement suggestions
- 🤖 AI-based code review assistance (planned)
- 📄 Generate meaningful feedback for developers (planned)

---

## Tech Stack

- **Programming Language:** Python
- **AI Technology:** Large Language Models (LLMs)
- **Version Control:** Git & GitHub
- **Development Environment:** Visual Studio Code

Installation & Setup
Step 1: Clone the Repository
git clone https://github.com/nikki-786/python_AI_Code_Reviewer.git
Step 2: Navigate to Project Directory
cd python_AI_Code_Reviewer
Step 3: Create Virtual Environment
python -m venv .venv
Step 4: Activate Virtual Environment

For Windows:

.venv\Scripts\activate
Step 5: Install Dependencies
pip install -r requirements.txt
Usage

Run the application using:

python app.py
